# HCV Fashion Hub

HCV Fashion Hub is a modern fashion e-commerce web application designed to provide a seamless and elegant online shopping experience. The platform showcases curated collections for men, women, and children, featuring responsive design, secure user authentication, intuitive navigation, and a clean user interface.

## Features
- User Authentication (Login & Signup)
- Responsive Design
- Product Categories
- Modern UI with Tailwind CSS
- State Management with Zustand
- RESTful API Integration
- MongoDB Database
- Shopping Experience Optimized for Desktop and Mobile

## Tech Stack
### Frontend
- React.js
- React Router DOM
- Tailwind CSS
- Zustand
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

## Project Goal
To create a premium online fashion destination that combines modern web technologies with an elegant shopping experience, making fashion accessible and enjoyable for all users.
